# iPhone Backup Extractor

A small Windows app that unlocks an encrypted iPhone backup made with Apple Devices or iTunes and sorts its hashed files into readable folders. Photos, videos, messages, contacts, voice memos, notes and app documents each get their own folder, and WhatsApp media is organized by chat. Messages and WhatsApp chats are also exported to CSV files you can open in Excel. Everything runs locally and your backup password is never saved.

## Use

Double-click `Start.bat` (needs Python 3). It installs one dependency on first run, then opens the app. Pick your backup folder, choose where to save, enter the backup password and click Start.
